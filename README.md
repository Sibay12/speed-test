# Tekna Technologies Speed Test // Next-Gen HUD Network Diagnostics

A futuristic, high-performance web-based internet speed test application inspired by advanced AI interfaces (JARVIS). Designed with a sleek dark-mode glassmorphic HUD, real-time voice feedback, and 11 multi-server regional/global nodes.

## 📁 Files Included
* `index.html` — Main UI with multi-server selection and legal footer links
* `style.css` — Futuristic glassmorphic HUD styling & responsive rules
* `script.js` — Speech synthesis, node routing, ping/download/upload logic
* `terms.html` — Terms & Conditions page
* `privacy.html` — Privacy Policy page
* `refund.html` — Refund Policy page
* `safety.html` — Safety Guidelines page
* `license.html` — License Agreement page

## 🌐 Deployment Instructions
Upload all these files directly into the **`public_html`** directory of your web hosting control panel (cPanel) or static hosting environment.
