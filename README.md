# Tekna Technologies Speed Test // Next-Gen HUD Network Diagnostics

A futuristic, high-performance web-based internet speed test application inspired by advanced AI interfaces (JARVIS / Alexa). Designed with a sleek dark-mode glassmorphic HUD, real-time voice feedback, and multi-server routing.

---

## 🚀 Key Features

* **Futuristic HUD Interface:** Built using modern CSS glassmorphism, glowing grid backgrounds, and animated radial speed gauges.
* **AI Voice Simulation:** Integrated browser speech synthesis provides live auditory diagnostic updates and final results in a robotic AI tone.
* **Multi-Server Node Architecture:** Supports **11 global and regional nodes** (including Reliance Jio hubs, Airtel, BSNL, AWS Mumbai, Azure, Cloudflare, and Google Edge) for precise localized routing performance tests.
* **Comprehensive Telemetry:** Real-time calculation and display of **Ping (Latency)**, **Download Speed**, and **Upload Speed**.
* **Zero Dependencies / Lightweight:** Pure HTML5, CSS3, and vanilla JavaScript with no heavy backend frameworks required.

---

## 📁 Project Structure

The project consists of three core files:
1. `index.html` — Main layout, HUD elements, and server selection options.
2. `style.css` — Futuristic styling, neon color schemes, and responsive grid layouts.
3. `script.js` — AI voice synthesis logic, network ping measurement, and download/upload simulation algorithms.

---

## 🌐 Deployment Instructions

This application is completely static and can be hosted on any web server or static hosting provider:

1. **cPanel / Traditional Web Hosting:**
   * Log into your hosting control panel or File Manager.
   * Navigate to the **`public_html`** root directory.
   * Upload all three files (`index.html`, `style.css`, and `script.js`) directly into `public_html`.
   * Access your domain to run the test.

2. **Static Hosting Providers (Netlify, Vercel, GitHub Pages):**
   * Create a new repository or drop the folder directly into the dashboard.
   * Deploy instantly as a static web app.
